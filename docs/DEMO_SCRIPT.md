# JAS OS 2-5 minute demo script

The repository includes an authentic [2:26 Oracle VirtualBox recording](JAS-OS-demo.webm).
Use this narration while playing it, or follow the same commands live.

## 0:00-0:20 - Introduction

> My project is JAS OS, a freestanding 32-bit x86 educational operating system.
> It boots from my own ISO and demonstrates the main CSE 323 concepts from
> chapters 1 through 13. Chapter 14 onward is outside my scope.

Command: `teacher`

Point out the Files, Notes, Terminal, Task Manager, Calculator, Settings, Clock,
and OS Lab sidebar applications. Mention that the terminal Guide is designed for
a teacher demonstration.

## 0:20-0:35 - Kernel overview

Command: `present 1`

> This is live kernel state, including the scheduler, memory, paging, file system,
> and I/O modules. The values are generated by the kernel, not hard-coded labels.

## 0:35-0:55 - Processes and IPC

Command: `present 3`

> JAS OS has task control blocks and lifecycle states. This mailbox demonstrates
> explicit send and receive, and the task table shows the running shell.

## 0:55-1:12 - CPU scheduling

Command: `present 5`

> I implemented Round Robin, Priority, FCFS, and SJF. The policy can be changed
> at runtime, and this timeline records which task received recent CPU slices.

## 1:12-1:35 - Synchronization and emergency stop

Command: `present 6`, then `stop`

> The readers-writers tasks share data using my semaphore implementation.
> Multiple readers may enter together, while the writer gets exclusive access.
> My global stop ends all non-shell background tasks but keeps the terminal ready.

## 1:35-1:50 - Deadlock avoidance

Command: `present 7`

> This is a real Banker's safety calculation over allocation, maximum, need, and
> available resource matrices. A request is granted only if a safe sequence remains.

## 1:50-2:05 - Virtual memory

Command: `present 9`

> The paging module translates process virtual addresses, allocates six frames,
> counts hits and faults, tracks dirty pages, and performs FIFO replacement.

## 2:05-2:26 - Storage and I/O

Commands: `present 12`, `present 13`

> The disk lab compares FCFS, SSTF, SCAN, C-SCAN, and C-LOOK using total head
> movement. The I/O lab compares polling, interrupts, and DMA with live counters.
> Together, these features implement the main knowledge through chapter 13.

## Useful answers during questions

- **Is it a real OS?** It is a real bootable freestanding kernel; educational
  paging, disk, RAID, and I/O models are clearly labeled as simulations.
- **Why cooperative tasks?** They make every transition bounded and inspectable,
  keeping the scheduling algorithms small enough to explain.
- **How do you stop output?** Use `stop` or the red STOP button. All non-shell
  background tasks are terminated and the shell remains responsive.
- **What did you exclude?** Chapter 14 onward, user-mode isolation, networking,
  and production disk/device support.
