# JAS OS silent demonstration voice-over script

This script matches `JAS-OS-Silent-Terminal-Demo.mp4`. The recording intentionally
contains no sound so narration can be added later. Read naturally; exact wording
is less important than staying close to the scene currently visible.

## 0:00-0:12 — Boot and desktop

This is JAS OS, my freestanding 32-bit x86 course-project operating system. I
built it to implement, test, and prove my own understanding of the main CSE 323
operating-system concepts from Chapters 1 through 13.

## 0:12-0:29 — Understanding guide

The terminal guide maps each lecture chapter to live evidence inside my kernel.
The output is generated by real kernel modules and changing kernel state, not by
hard-coded screenshots.

## 0:29-0:47 — Kernel overview

Chapter 1 demonstrates the kernel overview. JAS OS boots from a BIOS ISO, enters
32-bit protected mode, initializes interrupts, memory, scheduling, storage, the
keyboard, and the PS/2 mouse, and then starts the graphical shell.

## 0:47-1:05 — Processes and IPC

Chapter 3 shows processes and inter-process communication. The task table stores
task identifiers, states, priorities, and execution statistics, while the IPC
demonstration passes messages through kernel-managed queues.

## 1:05-1:23 — CPU scheduling

Chapter 5 compares CPU scheduling policies. The scheduler can use round-robin,
first-come first-served, shortest-job-first, priority, and multilevel feedback
queue behavior, and the output reports the resulting execution order.

## 1:23-1:53 — Synchronization and readers-writers

Chapter 6 implements synchronization using semaphores and a bounded-buffer
model. The readers-writers demonstration creates concurrent reader and writer
tasks and protects shared state from unsafe access.

## 1:53-2:09 — Global STOP

The stop command immediately ends all activity started from the terminal. It
terminates named demonstrations and extra background tasks while keeping the
terminal shell responsive and ready for another command.

## 2:09-2:28 — Deadlock avoidance

Chapter 7 implements the Banker's safety algorithm. The kernel evaluates the
available, allocated, and required resources and reports a safe execution
sequence when one exists.

## 2:28-2:47 — Virtual memory

Chapter 9 demonstrates paging and virtual memory. The kernel tracks pages,
frames, mappings, page faults, and replacement behavior so I can inspect the
state produced by the implementation.

## 2:47-3:23 — File system and storage

Chapters 10 and 12 connect the file-system interface to the storage model. JAS
OS supports files and directories, path handling, allocation information, disk
scheduling, and storage statistics through both commands and graphical apps.

## 3:23-3:39 — I/O systems

Chapter 13 demonstrates the I/O path. Keyboard and PS/2 mouse input arrive
through hardware interrupts, while terminal, graphics, storage, and device state
provide visible output.

## 3:39-3:47 — Dashboard

The dashboard collects live evidence from the kernel in one place, including
tasks, scheduler policy, memory, paging, synchronization, storage, and I/O.

## 3:47-3:54 — Project identity

JAS OS is a course-concept kernel rather than a general-purpose production
operating system. Its purpose is to make my understanding observable through
source code, commands, state transitions, and reproducible demonstrations.

## 3:54-4:00 — Commands and closing

The help screen lists the commands that can be used during evaluation. The same
features are also available through the terminal buttons, sidebar applications,
OS Lab, and task manager. The bootable ISO, source code, STAR technical report,
and demonstration files are included in the GitHub repository.
